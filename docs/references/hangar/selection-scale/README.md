# Hangar ship sizes

These are framebuffer captures from the ship selector at 1280 × 800 after its automatic camera approach. Only the hangar display sizes changed; flight models and collision sizes did not.

| Ship | Hangar scale | Capture |
| --- | ---: | --- |
| Star Wars N-1 | 1.50× | [Star Wars](starwars.png) |
| Smiling Friends | 1.30× | [Smiling Friends](smilingfriends.png) |
| Minecraft End Ship | 1.10× | [Minecraft](minecraft.png) |
| Halloween witch broom | 1.30× | [Halloween](../../halloween/hangar_front.png) |

The other two selector entries retain their prior size.

The Star Wars view uses a frontal camera and a gentle turn to keep its two engines visually balanced: [maximum turn](starwars-sway.png). Minecraft uses a slightly wider view aimed higher so the mast remains in frame from the [side](minecraft-side.png) and [back](minecraft-back.png). Camera changes glide as ships are selected.

Halloween also uses a wider, higher view so the witch's hat and broom stay in frame from the [side](../../halloween/hangar_side.png) and [back](../../halloween/hangar_back.png).
