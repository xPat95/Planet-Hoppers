# Ship identity in the hangar

The ship name uses smaller, uppercase, white Orbitron with a subtle black shadow centered near the top. The universe logo is centered directly beneath it. Logo bounds are balanced by shape; Halloween has no logo and appears last. The former top labels, ship description, and bottom control hint are removed.

All six previews now use the same close camera. Switching ships keeps the camera position and field of view fixed, and the platform rotation continues without resetting. Regular Show uses the common front-facing presentation, keeping Rigby below the logo.

The hangar lighting now keeps distant baked surfaces dimmer, uses a cool key on the displayed ship, and adds a subtle violet portal rim.
