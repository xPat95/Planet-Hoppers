# Revisión visual — nave Butters

Modelo basado en la imagen concepto adjunta por el usuario: caja de cartón cerrada, cara frontal, pelo amarillo, ventanas de plástico, cinta, propulsores dobles, pequeñas alas y emblema SP. La referencia original se consultó en la conversación; estos archivos son renders del modelo 3D.

- [Vista principal 3/4](butters_ship_three_quarter.png).
- [Vista lateral](butters_ship_side.png).
- [Vista frontal](butters_ship_front.png).
- [Vista 3/4 trasera: propulsores dobles](butters_ship_rear_three_quarter.png).

Renders de 1280 × 960 con Cycles, 32 muestras y reducción de ruido. Las vistas ortogonales ocultan el suelo de presentación para evitar una línea de horizonte que cruce la nave.
